## สิ่งที่ reviewer ฝากไว้ (ยังไม่ได้ทำ ต้องตัดสินใจใน change ใหม่)

- **Quality lane `go test ./...` wired automatically at high confidence** — Bare `go test ./...` prints only `ok <pkg>` with no countable summary. The auto-wired provider's discovery will be inconclusive, and the `verifyCountAdvisories` advisory covers task verify commands only, not generated providers. The spec does not say whether the fallback should add `-v` or warn.
- **Multi-module quality discovery (`test:<module>` lanes found by discovery rather than by quality config)** — The fallback reads only `providers.test` from discovery, so modules that discovery proposes as `test:svc` lanes give an unresolved result. The spec names only discovery's single test provider.
- **Maven Surefire total line with extra suffix fields (for example `Flakes:`), and hour-long Dart timestamps (`01:02:03`)** — Both stay uncounted by design (exact shapes only), but the spec does not say whether newer runner output variants should count.
- **Report directory placed in a task-scope check or workspace hash when it is not git-ignored** — The generated-report exemption in `proof-readiness.mjs` compares exact file paths, so files under a configured report directory are not exempt from changed-surface checks. The spec covers reading the directory but not its place in the changed surface.
