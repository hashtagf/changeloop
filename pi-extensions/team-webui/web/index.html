How Pi Workspace works

Session

  • หลัก: session ใน terminal ของ Pi · ย่อย: agent ที่ session นั้นสร้าง แสดงใต้ตัวแม่
  • กำลังทำงาน: ไม่ว่าง · ว่าง: พร้อมรับข้อความ · บันทึกไว้ · ออฟไลน์: ประวัติแบบอ่านอย่างเดียว

การส่งข้อความ

  • ต่อคิวหลังงานปัจจุบัน: ส่งเมื่องานเดิมเสร็จ
  • แทรกในรอบถัดไป: เปลี่ยนทิศทาง agent ในขั้นถัดไป

ขั้นงาน

  • รอเริ่ม → สำรวจ → ตกลงขอบเขต → พัฒนา → ตรวจหลักฐาน → นำเข้าโปรเจกต์ → ส่งมอบ → รวมโค้ด → ออกเวอร์ชัน → ขึ้นระบบ · การย้ายการ์ดบันทึกสถานะเท่านั้น ไม่รัน Git หรือขึ้นระบบ

สิทธิ์เข้าใช้

  • สมาชิก: ใช้แชท ไฟล์ Git และงานได้เต็มที่ · ผู้ชม: ดูอย่างเดียว
  • สมาชิกสร้างลิงก์เชิญที่หมดอายุ เพิกถอน และดูกิจกรรมล่าสุดได้ที่ปุ่ม สิทธิ์เข้าใช้

คู่มือเต็ม: team-webui/README.md ในแพ็กเกจ pi-extensions

Sessions

  • Main: a Pi terminal session. Sub: an agent it started, shown under its parent.
  • Working: busy now. Idle: ready for a message. Saved · offline: read-only history.

Sending

  • Queue after task: delivered after the current work finishes.
  • Steer next turn: redirects the agent at its next step.

Task stages

  • Open → Investigate → Change → Build → Prove → Land → Deliver → Merge → Tag → Deploy. Moving a card records status only; it never runs Git or deploys.

Access

  • Member: full access to chat, files, Git and tasks. Viewer: read only.
  • Members can create expiring invites, revoke them and review recent activity under Access.

Full guide: team-webui/README.md in the pi-extensions package.
